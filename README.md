# Estruturas_de_dados
Parágrafo breve (para README): Este repositório reúne minhas implementações e anotações sobre estruturas de dados (listas, pilhas, filas, árvores, grafos, tabelas hash etc.), desenvolvidas a partir do livro "Entendendo Estruturas de Dados" do Marcello La Rocca e complementadas por exercícios próprios.
